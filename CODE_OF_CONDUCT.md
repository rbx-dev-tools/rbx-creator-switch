# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, keep disagreements about the code.
Harassment of any kind is not tolerated.

Report a problem to <bap.extensions@gmail.com>, which reaches the maintainer
and nobody else.
Reports are handled within a week and the reporter's identity is not shared.
